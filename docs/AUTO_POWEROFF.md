# AI Passport 电池自动关机

日期：2026-11-10。适用 `research/live-camera-monitor`，ESP32-C3 AI Passport。

“关机”使用深睡眠实现，不是硬件断开电池。新增计时器独立于原有亮屏事件及 30 秒息屏策略，计时从条件同时成立开始，不从开机或最后按键时间计算。

| 当前条件／事件 | 关机计时与动作 |
| --- | --- |
| 已息屏、USB 未检测到连接、没有已知活动打印任务、无待处理亮屏请求 | 开始连续十分钟计时 |
| 上述条件保持不足十分钟 | 保留网络与原有事件亮屏能力 |
| 上述条件连续保持满十分钟 | 请求后台任务，重新检查最新供电、打印事件、按键和屏幕状态 |
| 插电、发现活动任务、亮屏请求或按键 | 取消并清零计时；再次满足条件时重新计时 |
| 任一机器仍为 `RUNNING`／`PAUSE`／`PREPARE`，即使本机黑屏／云断线 | 不关机，不把暂时断线当成任务完成 |
| `IDLE`／`FINISH`／`FAILED` 或尚无已知活动任务 | 可以计时；现实状态无法在断网时保证，一切依据已有遥测 |
| 任务排队后收到按键、插电、打印事件或待处理亮屏请求 | 放弃请求，保持运行；亮屏优先 |
| 拆卸外设后才出现活动，或关键准备步骤失败 | 重启恢复完整应用，不复用已拆卸的显示／输入驱动 |

关机在独立任务中执行，避免共享 `esp_timer` 回调等待网络或音频。进入终端准备阶段先持有禁止自动轻睡眠锁，避免拆卸期间时钟或唤醒定时器变化；显式深睡眠不受该锁阻止。停止相机、周期请求、MQTT 和 WiFi，等待提示音结束并关闭 codec／I2S；休眠 CW2017、关闭 LCD／背光、设置总线安全电平；把三键共用 GPIO0 从 ADC 切回数字输入，清除旧唤醒源，只保留低电平按键唤醒，不设置周期定时重启。

按任意键重新启动，恢复 NVS 中的页面及配置，开机的那次按键手势不会额外翻页。深睡后 WiFi／MQTT 关闭，不能再由打印开始／完成自动亮屏，也不能保证插 USB 自动启动；需要按键或复位重新开机。这与保留网络的轻睡眠不同，依据见 [ESP-IDF 睡眠模式](https://docs.espressif.com/projects/esp-idf/en/v5.5.3/esp32c3/api-reference/system/sleep_modes.html)。

插电判断与闪电图标共用电脑 USB 主机 SOF 检测，不能可靠识别普通充电头／充电宝，不能通过电池电压上涨代替可靠的 VBUS 输入。GPIO0 使用板上 10k 外部上拉，禁用额外内部睡眠上拉，避免改变三键分压。LCD 的 MOSI/GPIO9 在保持期间置高，兼顾 C3 启动绑带电平；[官方启动模式说明](https://docs.espressif.com/projects/esptool/en/latest/esp32c3/advanced-topics/boot-mode-selection.html)说明了 GPIO9 的作用。

深睡是低功耗停机，不代表电池电流为零；实际电流需要仪表测量。

实现：`app_screen_policy.c` 的独立关机计时、`app_poweroff.c` 的请求复核与硬件执行、`app_mqtt_has_active_job()` 的多机任务保护，以及 BSP 现有外设休眠接口。

## 验证记录

以下实机记录使用旧分区布局。Core 1.5.2 的新布局见 [安装指南](INSTALL.md)，需独立验证。

59 项主机测试通过，包括直接编译固件关机策略与执行函数，以虚拟时钟验证 599.999999 秒不关机、600 秒触发、计时重置、重复调度抑制、多机／离线活动任务保护、排队期间的新事件、执行期间新活动、输入不可读／按住、分配失败以及各外设准备失败的处理。开机手势覆盖按住至初始化后释放、初始化前已松开和延迟 CLICK，既不意外翻页，也不吞掉下一次有意按键。原亮屏、休眠、打印事件、相机、配置和通知回归同时通过。

ESP-IDF 5.5.3 / ESP32-C3 构建通过。首轮板上保留真实打印状态，打印机处于 `RUNNING`，设备未触发息屏或关机，确认活动任务保护。

硬件正向测试使用临时诊断固件，将阈值压缩到 10 秒，并仅在计时／执行层模拟“电池、空闲”输入，实际打印机数据与控制没有改写。原 30 秒息屏后约 11 秒开始关机，包含每秒检查的调度误差。CW2017 睡眠寄存器回读通过，LCD 和背光休眠、GPIO0 高电平及深睡启动日志正常；90 秒诊断定时唤醒后重新启动并恢复显示与电量计。用户另确认按实体键可以开机并恢复原页面。未向打印机发送控制命令。

诊断源码已恢复：正式阈值为 600 秒，使用真实 USB／打印状态，清除旧唤醒源后只启用 GPIO0，不保留模拟输入或周期定时唤醒。实际电池连续等待十分钟的电流／续航未测；不能把压缩计时测试描述为十分钟实耗验证。原始日志、诊断 ELF 和配置备份留在本地忽略目录。

最终正式固件已写入并校验，原 24 KiB NVS 回读一致。45 秒启动观察中 USB 已连接、打印机为 `RUNNING`，没有息屏或关机请求，云连接建立后无断开、无崩溃。正式计时边界由虚拟时钟测试覆盖，板上压缩测试验证外设与深睡／开机路径。

测试期间相机 6000 端口会在 TLS 握手阶段断开，电脑独立连接也收到 `ConnectionResetError`；云端打印状态可读取。此轮不以相机新帧作为关机通过条件，也不据此归因固件故障。
